Vengeful Realms Civil War Map

Upload these files to the root of a GitHub repository:

- index.html
- style.css
- script.js
- WarMapBase.png
- logo.png (optional)
- RealmsBG.png (optional)

Enable GitHub Pages from:
Settings > Pages > Deploy from a branch > main > /root

The map works without logo.png and RealmsBG.png, but adding your normal files will make it match your other Vengeful Realms sites.
